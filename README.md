# Charuvi Suresh — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript and deployed on GitHub Pages.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. No build step or package installation is required.

## Site contents

- Intro, biography, and contact details
- Featured OrdInex project and filterable project gallery with implementation details
- Experience, education, and resume-sourced certifications/courses
- GitHub profile and selected repository links (no third-party statistics images)
- Dark/light theme, responsive navigation, and reduced-motion support

The project gallery links to selected public repositories. Use the GitHub profile link in the activity section to view current contributions and all public projects.

## Customize

- Update portfolio content, links, experience, and projects in `index.html`.
- Adjust styles, design tokens, and responsive layouts in `style.css`.
- Update theme, navigation, project filtering, and animation behavior in `script.js`.
- Replace `Charuvi-Suresh-Resume.pdf` when the resume is updated; the page links to this local PDF for download.
- Contact actions use direct email links. The site has no message form or backend.

## Deploy

This is a static GitHub Pages site with no build step. Test `index.html` locally, then push the site files to the `main` branch of `chxrxv.github.io` to publish.
