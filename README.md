# Charuvi Suresh — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript and deployed on GitHub Pages.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. No build step or package installation is required.

## Site contents

- Intro, biography, and contact details
- Featured OrdInex project and filterable project gallery
- Experience, education, and certifications
- GitHub profile statistics and contribution activity
- Dark/light theme, responsive navigation, and reduced-motion support

The project gallery highlights selected public repositories. Use the GitHub link below the gallery to explore all public projects, including course work and experiments.

## Customize

- Update portfolio content, links, experience, and projects in `index.html`.
- Adjust styles, design tokens, and responsive layouts in `style.css`.
- Update theme, navigation, project filtering, and animation behavior in `script.js`.
- The resume button is intentionally omitted until a real resume PDF is added.
- The contact form opens a prefilled message in the visitor's default email app. It does not store or send messages through a backend.

## Deploy

Push the site files to the `main` branch of `chxrxv.github.io` to publish them with GitHub Pages.
